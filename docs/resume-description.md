# 简历项目描述

## 一句话版本

基于 FastAPI、PostgreSQL/pgvector、Celery、Redis 和 OpenAI-compatible 模型接口构建企业级智能知识库问答系统，实现多格式文档异步入库、混合检索、引用溯源和无依据拒答。

## 简历三条版本

**企业级智能知识库问答系统｜Python / FastAPI / PostgreSQL / pgvector / Celery / Redis / RAG**

- 设计并实现用户注册登录、JWT 鉴权和知识库级数据隔离，支持 PDF、DOCX、Markdown、TXT 文档上传，通过 Celery + Redis 完成解析、清洗、重叠分块和异步向量化。
- 基于 pgvector HNSW 向量检索与 PostgreSQL GIN 全文检索构建双路召回，使用 RRF 融合和可解释重排序，并通过动态证据门控实现引用溯源与知识库外问题拒答。
- 建立包含 6 份脱敏制度文档和 30 条问题的自动评测体系；在该演示集上实现 Hit@5/Recall@5/MRR@5、引用准确率和拒答通过率均为 100%，平均检索与重排序耗时约 391 ms。

## 面试展开版本

项目重点不是简单调用大模型，而是构建完整、可评估的 RAG 工程链路：

1. 文档处理与在线问答解耦，避免大文件上传阻塞 API。
2. 向量检索解决语义表达差异，全文检索补充制度编号、金额和关键词查询。
3. RRF 避免直接比较不同检索器的原始分数。
4. 证据门控要求问题和来源文本达到绝对及相对阈值，防止弱相关向量触发幻觉回答。
5. 通过标准问题集而非主观体验衡量检索、引用和拒答效果。

## 指标表述注意

推荐说：

> 在自建的 6 份企业制度、30 条标准问题演示集上，Hit@5 和拒答通过率达到 100%。

不要说：

> 系统准确率在任何企业场景下都达到 100%。
