# 安全说明

## 已实现

- 密码使用 Argon2 推荐配置进行不可逆哈希。
- 受保护接口使用 JWT Bearer Token。
- 知识库、文档、任务、会话都进行当前用户所有权过滤。
- `.env`、上传文件和运行缓存不进入 Git。
- 对话模型与 Embedding 模型使用独立凭证。
- 日志不输出模型 API Key、JWT Token 或数据库密码。
- 响应增加请求 ID、安全响应头和统一内部错误格式。
- CORS 来源通过环境变量限制。
- 文件上传限制扩展名、空文件和最大体积。
- 知识库外问题由证据门控拒答。

## API Key 管理

真实密钥只应填写在本机或服务器的 `.env` 中：

```text
LLM_API_KEY
EMBEDDING_API_KEY
```

禁止：

- 将 `.env` 提交到 Git。
- 在 README、Issue、截图或日志中展示完整密钥。
- 将服务端密钥发送到浏览器前端。
- 在生产和开发环境长期复用同一个密钥。

如果密钥曾被意外输出或提交，应立即在模型供应商控制台撤销并生成新密钥，仅删除 Git 文件并不足以消除泄露风险。

## 上线前必须完成

- 修改 `SECRET_KEY`、数据库密码和默认账号。
- 使用 HTTPS。
- 关闭 API 的开发热重载。
- 限制数据库和 Redis 仅在内部网络访问。
- 增加登录、上传和模型调用限流。
- 增加文件病毒扫描和更严格的 MIME 校验。
- 增加 Token 撤销或短期 Access Token + Refresh Token。
- 增加数据库备份、恢复演练和日志留存策略。
