# 项目演示脚本

建议演示时长：5-8 分钟。

## 1. 项目介绍（30 秒）

“这是一个面向企业内部员工的智能知识库问答系统。它支持多格式文档异步解析、向量与全文混合检索、证据重排序、严格 RAG 问答、引用溯源和无依据拒答。”

## 2. 登录和知识库（45 秒）

1. 打开 `http://localhost:8501`。
2. 登录演示账号。
3. 创建“员工制度知识库”。
4. 说明 JWT 鉴权和用户级数据隔离。

## 3. 文档处理（60 秒）

1. 上传 Markdown、PDF 或 Word 文档。
2. 展示排队中、处理中、已完成状态。
3. 打开 Worker 日志，说明 Celery + Redis 异步处理。
4. 说明解析、分块、Embedding 和 pgvector 入库过程。

## 4. RAG 问答（90 秒）

先提问知识库内问题：

```text
上海出差住宿标准上限是多少？
```

展示：

- 回答内容
- `[S1]` 引用
- 来源文件和原文片段
- grounded 状态
- Trace ID 和耗时

再提问知识库外问题：

```text
公司今天的股票价格是多少？
```

展示系统明确拒答，并解释证据门控如何降低幻觉。

## 5. 评测展示（60 秒）

打开“评测报告”标签页，展示：

- Hit@5 / Recall@5 / MRR@5
- 引用准确率和覆盖率
- 知识库外问题拒答通过率
- 分类指标和失败样例

说明 100% 结果只适用于项目自建的 30 条演示数据集，不代表所有真实业务数据。

## 6. 架构总结（45 秒）

打开 `docs/architecture.md`，按以下顺序讲解：

```text
Streamlit -> FastAPI -> PostgreSQL/pgvector
                       -> Redis/Celery
                       -> Chat/Embedding API
```

最后说明下一步可扩展多租户 ACL、MinIO、独立 Reranker 和可观测平台。
